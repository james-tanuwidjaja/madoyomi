## Failures and triage

Classes: **HOST_GAP** (Madoyomi lacks an API the extension needs: ours to fix), **CLOUDFLARE** (the site answers with a Cloudflare challenge; needs a solver), **SITE_DOWN** (DNS, connection or 5xx at the site), **WEBVIEW** (the source renders in a real WebView, and the sidecar runs with KCEF off; deferred with the WebView shim), **UPSTREAM_BROKEN** (the extension no longer matches its site; broken in Aniyomi too), **SOURCE_ERROR** (the source failed, not yet triaged further), **INTERNAL**, **JVM_ABORT**. The site probe is a plain GET of the source's base URL from PowerShell with a browser user agent, so it can differ from what OkHttp gets.

- **animepahe** (SAFE): CLOUDFLARE at popular (automatic: CLOUDFLARE). `[SOURCE_FAILED] Cloudflare bypass currently disabled details={"reason":"CLOUDFLARE"}`. site probe `animepahe.pw`: HTTP 403, server cloudflare, Cloudflare challenge.
  - Triage: The site answers OkHttp with a Cloudflare challenge (403, Server: cloudflare); the extension's own WebView bypass gives up after about 60 s and upstream's CloudflareInterceptor has no solver (FlareSolverr off). Needs a Cloudflare solver; deferred (Phase 2 section 9, Stage 5).
- **hentaihaven** (NSFW): SITE_DOWN at videos (automatic: SITE_DOWN). `[SOURCE_FAILED] hoster 'Octopus': Failed to connect to octopusmanifest.org/195.16.73.90:443 (hosters=1)`. site probe `hentaihaven.xxx`: HTTP 403, server cloudflare, Cloudflare challenge.
  - Hoster errors: Octopus: [SOURCE_FAILED] Failed to connect to octopusmanifest.org/195.16.73.90:443
  - Triage: Browse and details work (OkHttp gets past the site's Cloudflare, PowerShell's probe doesn't). Its only hoster, Octopus, needs octopusmanifest.org, which resolves (195.16.73.90) but refuses TCP 443 from this network (Test-NetConnection, 2026-11-06): the video host is down or blocked here. Not a Madoyomi gap.
