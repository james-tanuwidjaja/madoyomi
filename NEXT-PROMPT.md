Gotchas:
- If your shell is a Linux VM (device_bash) rather than Windows, the Windows side runs through the agent job runner: ask me to start tools\dev-data\agent\start-runner.cmd (check runner.heartbeat is fresh). Each queue\NNN-name.ps1 runs once, hidden; its output is queue\NNN-name.log and its exit code queue\NNN-name.done (the last job was 260). **Jobs run in parallel**: wait for one's .done before queueing the next if they share anything (a job can wait itself: `while (-not (Test-Path "$q\NNN-x.done")) { Start-Sleep 5 }`). Git runs there too (`git switch`, `git pull`): the VM can't delete files in the repo, which git needs. Make the branch before your first edit: an edit made on main only moves with `git switch -c` because it is uncommitted. Scratch helpers there (gitignored): app-start6.ps1 (`-DataDir <name under agent\>`, default fresh-data; starts `pnpm tauri dev` hidden, output in tauri-dev.log, waits for "healthy after"), app-stop.ps1 (closes the window, then lists what's left; a "madoyomi java still running" line can be another server of yours, check the data dir's sidecar.log for "backend stopped (exit code 0)"), front.ps1 (brings the app window forward and maximizes it), seed-live.ps1 (seeds live-data and runs the live spec), reader-live1.ps1 and reader-live2.ps1 (Stage 1's API checks on Webtoons and MangaDex; reuse their helpers to find a long chapter). - Gradle: run `ktlintFormat` and `build` as two separate invocations. Start it through `Start-Process` with `-PassThru` and `WaitForExit()` and an absolute `JAVA_HOME` (D:\Projects\madoyomi\tools\bin\jdk-21): a Gradle daemon keeps a redirected pipe open, so `cmd /c gradlew ... > file` inside a runner job never returns. Use `build --continue`, so api's tests run even when a core test fails. Don't rebuild while a backend runs from the jar. A backticked Kotlin test name can't contain `:` or `;` on Windows.
- Flaky: upstream's `CefTest` downloads a JBR live and sometimes gets `SocksProxyTest`'s transient SOCKS host (`UnknownHostException`). Rerun the build once before suspecting your change.

Keep .ps1 files ASCII. `ErrorText` (tools/lib/MadoyomiServer.ps1) takes a response's `.Json`, not the `Gql` result itself.
